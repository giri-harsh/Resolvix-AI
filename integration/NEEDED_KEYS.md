## Can Agora-managed ASR/TTS replace Deepgram / ElevenLabs? (checked in Agora's docs 2026-11-02)
**Partly.** Agora has a "managed mode": set `credential_mode: "managed"` in the `asr`, `llm` or `tts` block of the join request and Agora provides and bills the vendor key (no key from us). Per Agora's pricing/managed-mode pages:
- **ASR:** Deepgram `nova-2` / `nova-3` are listed as managed -> **the Deepgram key can very likely be dropped.** Hindi under managed mode is not documented (the `language` param still applies): test `language=multi` / `hi` first.
- **TTS:** the managed example uses **MiniMax** (`speech-2.6-turbo` / `speech-2.8-turbo`). **ElevenLabs is key-based only** (and Agora says a paid ElevenLabs plan is needed for reliable use). MiniMax Hindi quality is unverified: test it before relying on it. Sarvam (hi-IN ASR and TTS, key-based) is the other Hindi-specific option Agora lists.
- **LLM:** managed is OpenAI-class; we do not use it (our own Brain behind the custom-LLM URL).
- So the minimum key set could be: Agora App ID + Certificate + Customer ID/Secret (+ Conversational AI enabled) and nothing else for STT/TTS, plus the public tunnel. **Fallback if Hindi is poor:** add Deepgram and/or ElevenLabs/Sarvam keys. Sources: https://docs.agora.io/en/ai/build/custom-model-integration/managed-mode and https://docs.agora.io/en/ai/reference/pricing .

## Per credential
### Agora (RTC + Conversational AI)
- **Env vars:** `AGORA_APP_ID`, `AGORA_APP_CERTIFICATE`, `AGORA_CUSTOMER_ID`, `AGORA_CUSTOMER_SECRET`. Read by `voice-runtime/resolvix_runtime/config.py`; used in `agora_control.py` (token + join call) and the web-call page.
- **Provider / signup:** https://console.agora.io (create a project with **App Certificate enabled**; RESTful API Customer ID/Secret are under Developer Toolkit -> RESTful API; turn on the Conversational AI Engine for the project).
- **Free tier / limits:** the docs list the Conversational AI audio task at $0.10 per minute with the first 300 minutes free (**verify** on the pricing page; third-party sites quote other numbers). Core RTC has a separate 10,000 free minutes per month.
- **Public URL:** yes (see below).

### STT: Deepgram (default in code)
- **Env vars:** `ASR_VENDOR=deepgram`, `ASR_API_KEY`. Read by `config.py`, passed to Agora in the join payload (`agora_control.py`: `asr.vendor`, `asr.params.api_key`).
- **Hindi / Hinglish:** Deepgram Nova-3 supports Hindi (`hi`) and a multilingual mode (`language=multi`) with mid-sentence code-switching, Hindi included. Use `model=nova-3` with `language=multi` (or `hi`) for Hinglish callers. **The code does not set any language today** (see "Code risks" below).
- **Free tier:** Deepgram advertises a $200 sign-up credit (**verify** it is still offered). Signup: https://console.deepgram.com. Agora's docs also describe a managed mode (`credential_mode: "managed"`) in which Agora bills the vendor and no key is needed (**verify** which vendors).

### TTS: ElevenLabs (default in code)
- **Env vars:** `TTS_VENDOR=elevenlabs`, `TTS_API_KEY`, `TTS_VOICE_ID`. Read by `config.py`, passed in the join payload (`tts.vendor`, `tts.params.api_key`, `tts.params.voice_id`).
- **Hindi:** `eleven_flash_v2_5` (lowest latency, about 75 ms, 32 languages including Hindi; **verify**) or `eleven_multilingual_v2`. Pick a voice from the ElevenLabs voice library that handles Hindi and English and copy its voice id; the code falls back to the literal id `"default"`, which will not work.
- **Free tier:** ElevenLabs has a free plan with a small monthly character allowance (amount not confirmed: check https://elevenlabs.io/pricing). Hindi at a demo's length may exceed it. Signup: https://elevenlabs.io.
- Azure Speech, Cartesia and others are also supported by Agora (**verify** params); Azure is a possible fallback with Indian voices (hi-IN).

### Groq (Brain LLM)
- **Env vars:** `GROQ_API_KEY`, `LLM_MODE=live`, `LLM_MODEL` (default `openai/gpt-oss-120b`; **set `openai/gpt-oss-20b`**, see `brain/docs/LATENCY.md`: the 120b model often returns no text), `LLM_FALLBACK_MODEL`. Read by the Brain only (inside the runtime process), from the process environment or `brain/.env`.
- **Free tier:** Groq's console free tier has rate limits; our 60-call evaluation ran without throttling. Signup: https://console.groq.com. **Already working on Kamal's machine** (key in the repo-root `.env`).

### Shared secrets (no signup)
- `SERVICE_KEY` (ops, runtime), `KB_EXPORT_SERVICE_KEY` (Brain; must equal `SERVICE_KEY`), `SHIM_API_KEY` (Agora -> our `/v1/chat/completions`, sent as `Authorization: Bearer`), `SESSION_SECRET` and `SEED_PASSWORD` (ops dashboard). `integration/run_all.ps1` generates local-only random values if `integration/.env` is missing.

### Public HTTPS URL (REQUIRED for web-call)
- Agora's cloud calls the custom-LLM URL `PUBLIC_BASE_URL/v1/chat/completions?call_id=...` with the bearer `SHIM_API_KEY`, so `PUBLIC_BASE_URL` must be an HTTPS URL reachable from the internet and pointing to runtime port 8000.
- Quick options: `cloudflared tunnel --url http://localhost:8000` (free, no account for quick tunnels) or `ngrok http 8000`. Set `PUBLIC_BASE_URL=https://<tunnel-host>` before starting the runtime.
- Ops (8100) and the dashboard (5173) need no public URL. Ops needs `OPS_PUBLIC_URL` public only if Twilio status callbacks are used (optional phase).

### Phone phase (OPTIONAL)
- Twilio: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` (ops), `NOTIFY_MODE=twilio`; India requires DLT registration (sender id and each template), which takes days to weeks. PSTN calling needs an Agora PSTN/SIP number or a Twilio number with SIP trunking. Do not buy anything before the web-call works.

## Code risks in voice-runtime to fix during bring-up (found while writing this list; not yet tested against Agora)
1. **RTC token is not a real Agora token.** `agora_control.py:generate_rtc_token` builds `"006" + app_id + HMAC...` by hand. Agora expects the AccessToken2 ("007") format; this token will almost certainly be rejected when `AGORA_APP_CERTIFICATE` is set. Fix: use Agora's open-source token builder (AgoraDynamicKey, `RtcTokenBuilder2`) for the browser token and for the agent token.
2. **Join payload shape.** `_start_agora_agent` posts `{"name", "channel", "rtc":{"token"}, "parameters":{greeting, llm, asr, tts}}`. The current Agora reference describes `{"name", "properties": {"channel", "token", "agent_rtc_uid", "remote_rtc_uids", "llm": {...}, "asr": {...}, "tts": {...}}}` (docs differ between versions: **verify** against https://docs.agora.io/en/conversational-ai/rest-api/agent/join). The call has a 4 s timeout and only logs a warning on failure, so a wrong payload fails silently.
3. **No language set for ASR/TTS.** Hindi and Hinglish need an explicit ASR language (`multi`/`hi`) and a Hindi-capable TTS voice.
4. **Failure is silent.** If the join call fails the browser still joins an empty channel; surface the Agora error on the web-call page.
